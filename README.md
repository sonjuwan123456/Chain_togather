# Chain_Togather

**Chained Together** 스타일의 Minecraft Forge 모드입니다. 플레이어(또는 몹)를 사슬로 묶어 함께 움직이고, 함께 살고, 함께 죽습니다.

- Minecraft **1.21.1**
- Forge **52.1.20** 이상

## 기능

### 결속의 사슬
- 사슬 2개 + 끈 1개로 **결속의 사슬**을 조합합니다 (모양 없는 조합).
- 결속의 사슬을 들고 플레이어나 몹을 우클릭하면 사슬로 연결됩니다.
- 여러 명을 연결하면 하나의 그룹이 됩니다.

### 사슬 물리
- 사슬 길이(기본 6블록)보다 멀어지면 서로 끌어당깁니다.
- 매달린 상태에서 점프를 누르면 위에 있는 상대를 향해 사슬을 타고 올라갈 수 있습니다.
- 사슬에 매달려 있으면 낙하 피해가 쌓이지 않습니다.
- 사슬 길이의 4배 이상 떨어지면 상대 쪽으로 순간이동합니다.
- 사슬은 늘어지고 흔들리는 실제 체인으로 렌더링됩니다.

### 함께하는 운명
- **인벤토리 공유**: 그룹원끼리 메인 인벤토리와 핫바(36칸)를 공유합니다. 갑옷과 보조손은 각자 사용합니다.
- **상태 효과 공유**: 한 명이 효과를 얻거나 잃으면 그룹 전체에 적용됩니다.
- **함께 죽음**: 한 명이 죽으면 그룹 전체가 함께 죽습니다.
- **함께 이동**: 한 명이 차원을 이동하면 나머지도 따라갑니다. 리스폰하면 살아 있는 그룹원 옆에서 시작합니다.

### 사슬 내구도
- 사슬 내구도는 100%에서 시작합니다.
- 그룹원이 발전 과제를 달성할 때마다 내구도가 깎입니다 (과제 0.5%, 목표 2%, 도전 5%).
- 내구도가 0이 되면 사슬이 끊어지고 자유가 됩니다.
- 사슬에 묶여 있는 동안 화면 왼쪽 위에 남은 내구도가 바와 숫자로 표시됩니다.

### 구속 벨트
- 사슬에 묶인 플레이어는 허리에 철 구속 벨트를 찹니다.
- 사슬은 벨트 뒤쪽 고리에 연결됩니다.
- 가슴 갑옷을 입으면 벨트가 갑옷 위로 보이도록 커집니다.

### 사슬 소리
- 사슬이 팽팽해지면 소리가 납니다.
- 소리는 각 클라이언트에서 재생되므로 플레이어마다 따로 끄거나 줄일 수 있습니다.

## 설정

### 공용 설정 — `config/chain_togather-common.toml`
서버(또는 싱글플레이 월드)에 적용됩니다.

| 항목 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| `chainLength` | `6.0` | 2.0 ~ 64.0 | 사슬 최대 길이(블록) |
| `pullStrength` | `0.3` | 0.01 ~ 2.0 | 당기는 힘 |
| `taskDamage` | `0.5` | 0.0 ~ 100.0 | 과제 달성 시 내구도 감소량(%) |
| `goalDamage` | `2.0` | 0.0 ~ 100.0 | 목표 달성 시 내구도 감소량(%) |
| `challengeDamage` | `5.0` | 0.0 ~ 100.0 | 도전 달성 시 내구도 감소량(%) |

### 클라이언트 설정 — `config/chain_togather-client.toml`
각 플레이어가 자기 컴퓨터에서 설정합니다.

| 항목 | 기본값 | 범위 | 설명 |
|---|---|---|---|
| `chainSounds` | `true` | — | 사슬 소리 켜기/끄기 |
| `chainSoundVolume` | `1.0` | 0.0 ~ 1.0 | 사슬 소리 볼륨 배율 |
| `durabilityHud` | `true` | — | 화면 왼쪽 위 사슬 내구도 HUD 표시 |

## 빌드

Gradle 8.8로 빌드합니다. 저장소에 Gradle wrapper가 없으므로 IntelliJ의 Gradle 탭이나 설치된 Gradle을 사용합니다.

```sh
gradle build
```

결과물은 `build/libs/chain_togather-<version>.jar`에 생성됩니다.

### 테스트 클라이언트로 자동 복사
사용자 `gradle.properties`(예: `~/.gradle/gradle.properties`)에 `deployModsDir`를 설정하면, 빌드할 때마다 해당 폴더의 이전 jar를 지우고 새 jar를 복사합니다.

```properties
deployModsDir=C:/Users/<사용자>/curseforge/minecraft/Instances/<인스턴스>/mods
```

### 개발용 실행
- `runClient` — 클라이언트
- `runClient2` — 두 번째 클라이언트 (`run-client2` 폴더 사용, 멀티 테스트용)
- `runServer` — 전용 서버
